Commands & setup

Use slash commands or the default uwu prefix. Servers can change the prefix. Managers choose her chat channels and automatic-reply settings with /serversetup. Browse every command with /help.

Allowances & permissions

AI chat uses a daily server allowance, visible with /serverdashboard. Voice requires channel permissions. Elation requires channel and nickname permissions; managers use /elation stop, and participants can use /elation optout.

About the cards

Profile reviews use assets available through Discord's bot API, including an available avatar, banner, and decoration. Visual scores are estimates. Full profile effects and Discord's complete profile theme are not available to the bot.
