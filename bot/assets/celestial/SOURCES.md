# Local artwork sources

- Kenney, Fantasy UI Borders, CC0 1.0: https://kenney.nl/assets/fantasy-ui-borders
  Original license included in kenney/License.txt. Renderer uses panel-border-000.png with nine-slice scaling.
- Hyptosis, 200 Free Lorestrome Portraits, CC0: https://opengameart.org/content/200-free-lorestrome-portraits
  Original sheet downloaded from https://opengameart.org/sites/default/files/portraits.jpg
  Only the first eight rows (48 portraits) are used. Lower portions have visible artifacts and are excluded.
- Tarot source: Pamela Colman Smith, original Rider-Waite-Smith scans on Wikimedia Commons:
  https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC)
  Commons downloads were blocked by HTTP 429. The 22 major arcana images are now bundled
  from https://github.com/sixseeds/tarot-api (cards/ar00.jpg through ar21.jpg).
  Its README identifies the images as public-domain Rider-Waite (1909) artwork.
  Images are fitted to the spread and rotated 180 degrees when reversed.

Downloaded 2026-09-14. No command downloads these assets at runtime.
Additional downloaded assets:
- treeform, Spacy cloud/nebula backgrounds, CC0:
  https://opengameart.org/content/spacy-cloudnebula-backgrounds
  backgrounds/violet.png is blended into the dark layouts.
- Lorc, Game-icons.net, CC BY 3.0: https://creativecommons.org/licenses/by/3.0/
  Icons owl, fox-head, dragon-head and star-swirl are used as guardian emblems, resized.
  Source pages: https://game-icons.net/1x1/lorc/owl.html (replace slug for the other icons).
  Attribution appears on guardian images and in their accompanying Discord message.
  Other downloaded icons are not currently rendered. Kenney's generic UI Pack is not bundled.
